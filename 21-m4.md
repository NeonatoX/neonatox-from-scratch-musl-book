# Capítulo 21: m4

## 21.1 — Objetivo

Compilar m4 1.4.21, necesario para autotools (autoconf/automake) que
algunos paquetes requieren en su proceso de configuración.

## 21.2 — Dependencias

No tiene dependencias especiales más allá de GCC musl nativo.

## 21.3 — Compilar

```
cd /sources
rm -rf m4-1.4.21
tar -xf m4-1.4.21.tar.xz
cd m4-1.4.21

./configure --prefix=/usr

make -j$(nproc)
make install
```

## 21.4 — Verificar

```
m4 --version
# → GNU M4 1.4.21
```
