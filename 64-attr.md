# Capítulo 64: Attr-2.6.0

## 64.1 - Objetivo

Extended attribute support library for ACL support.

## 64.3 — Descargar

```bash
wget https://download.savannah.gnu.org/releases/attr/attr-2.6.0.tar.gz
```

## 64.4 — Compilar

```bash
./configure --prefix=/usr     \
            --disable-static  \
            --sysconfdir=/etc \
            --docdir=/usr/share/doc/attr
make


make install
```
