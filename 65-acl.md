# Capítulo 65: Acl-2.6.0

## 65.1 - Objetivo

Access control list utilities, libraries and headers.

## 65.3 — Descargar

```bash
wget https://download.savannah.gnu.org/releases/acl/acl-2.6.0.tar.gz
```

## 65.4 — Compilar

```bash
./configure --prefix=/usr    \
            --disable-static \
            --docdir=/usr/share/doc/acl
make


make install

```
